# Процедура анализа

**Срок:** 26 сентября (веха 1) · **Обновляется по итогам пилота**

Описание того, как именно материал превращается в результат.

**Требование к разделу:** другой исследователь, применив описанную процедуру к тому же материалу, должен получить сопоставимый результат.

## 1. Что определяется

**Единица анализа:** Кандидат в термины или ключевые слова, извлечённый пайплайном из документа корпуса. Кандидат представляет собой слово, словосочетание или устойчивую конструкцию, выделенную модулем извлечения.

**Что приписывается единице:**

| Атрибут | Тип | Описание |
|---------|-----|----------|
| Терминологический статус | категория (4 значения) | Канонический термин / вариант термина / квазитермин / не термин |
| Статус ключевого слова | бинарная метка | Является / не является ключевым словом документа |
| Концептуальная категория | категория (8–12 значений на домен) | Верхнеуровневый концепт домена |
| Связи | множественное значение | Синонимы и гиперонимы из числа других размеченных единиц |
| Доверие модели | количественная характеристика (0–1) | Уверенность пайплайна в извлечении данной единицы |

## 2. Система категорий

### 2.1. Терминологический статус

| Категория | Определение | Пример отнесения | Пример неотнесения |
|-----------|-------------|------------------|--------------------|
| **Канонический термин** | Устоявшаяся единица профессионального языка, зафиксированная в нормативных справочниках, глоссариях или энциклопедиях домена | «артериальная гипертензия» (медицина), «расторжение договора» (юриспруденция), «волатильность» (финансы) | «давление повышено» (описательная конструкция, не термин) |
| **Вариант термина** | Синонимичная, сокращённая или альтернативная форма канонического термина, используемая в профессиональной коммуникации | «АГ» (сокращение от «артериальная гипертензия»), «ингибиторы АПФ» (вариант полного названия) | «плохое давление» (бытовое обозначение, не вариант термина) |
| **Квазитермин** | Бытовое или описательное обозначение, выполняющее терминологическую функцию в данном контексте, но не зафиксированное в нормативных источниках | «шум в ушах» (вместо «тиннитус»), «отработка при увольнении» (вместо «срок предупреждения об увольнении») | «голова болит» (слишком общая конструкция, не выполняет терминологическую функцию) |
| **Не термин** | Общеупотребительная лексика, ошибочно извлечённая пайплайном; не выполняет терминологическую или ключевую функцию | «пациент», «документ», «процент» в общеупотребительном значении | «пациент» в контексте «права пациента» может быть термином |

### 2.2. Концептуальные категории по доменам

**Клиническая медицина:** симптом, диагноз, метод лечения, препарат, анатомическая структура, диагностическая процедура, показатель, осложнение.

**Юриспруденция:** субъект права, объект права, правовое действие, нормативный акт, процессуальное действие, санкция, правовой режим, договор.

**Финансы и экономика:** финансовый инструмент, экономический показатель, рыночный механизм, регуляторная норма, вид операции, риск, отчётная форма, участник рынка.

## 3. Порядок работы

1. **Извлечение кандидатов.** Пайплайн извлекает из каждого документа корпуса кандидатов в термины и ключевые слова статистическими методами (TF-IDF, C-Value, RAKE) и нейросетевыми методами (KeyBERT). Каждый кандидат получает числовую оценку уверенности модели.

2. **Векторизация.** Каждый кандидат преобразуется в плотный вектор с помощью модели `paraphrase-multilingual-MiniLM-L12-v2`. Векторы сохраняются в едином пространстве для последующей кластеризации.

3. **Кластеризация.** Векторы кандидатов группируются алгоритмом HDBSCAN с автоматическим определением числа кластеров. Каждый кластер интерпретируется как семантическая группа (концептуальное гнездо).

4. **Формирование подвыборки для разметки.** Из общего пула кандидатов методом стратифицированной случайной выборки отбираются 900 единиц: по 300 на каждый домен. Стратификация по уровням уверенности модели (высокая / средняя / низкая) и по концептуальным категориям.

5. **Экспертная разметка.** Три доменных эксперта (врач, юрист, экономист) размечают по 300 единиц своего домена. Два лингвиста независимо размечают пересекающуюся подвыборку (180 единиц из всех доменов) для расчёта межкодировочного согласия. Разметка проводится в слепом режиме в платформе Label Studio.

6. **Арбитраж и формирование золотого стандарта.** Для единиц с расхождениями координатор совместно с доменным экспертом выносит итоговое решение. Результат — согласованный набор из 900 единиц.

7. **Расчёт метрик.** На золотом стандарте рассчитываются Precision, Recall, F1-мера пайплайна извлечения — отдельно для каждого домена и в целом.

8. **Интеграция в RAG.** Извлечённая и верифицированная терминология добавляется в векторную базу знаний тестовой RAG-системы. Проводится A/B-тестирование: 100 запросов на домен, расчёт Precision@5 и Recall@5.

## 4. Спорные случаи

**Случай 1:** Единица «давление» в медицинском тексте. В контексте «измерение артериального давления» это часть канонического термина. В контексте «у пациента высокое давление» это квазитермин. В контексте «давление на пациента со стороны родственников» это не термин.

**Решение:** Терминологический статус определяется по контексту употребления, а не по лексической форме. Если единица входит в состав устойчивого терминологического словосочетания, зафиксированного в справочнике, она размечается как канонический термин (или вариант). Если выполняет терминологическую функцию, но не зафиксирована в нормативных источниках — как квазитермин. Если используется в общеупотребительном значении — не термин.

**Случай 2:** Единица «сделка» в юридическом тексте. Является ли она каноническим термином или общеупотребительным словом? В контексте Гражданского кодекса «сделка» — юридический термин с чётким определением (ст. 153 ГК РФ). В бытовом контексте «заключить сделку с другом» — общеупотребительное слово.

**Решение:** Если единица имеет нормативное определение в законодательстве или правовом справочнике и используется в тексте в этом значении, она размечается как канонический термин. Если используется в переносном или бытовом значении — не термин. При сомнении приоритет отдаётся контексту документа: в юридических документах по умолчанию предполагается терминологическое употребление.

**Случай 3:** Единица «хеджирование» в финансовом тексте. Термин пришёл из английского языка (hedging) и не имеет устоявшегося русского эквивалента. В одних текстах используется как калька, в других — с пояснением. Является ли он каноническим термином или квазитермином?

**Решение:** Англицизмы, зафиксированные в официальных документах ЦБ РФ, финансовых словарях или стандартах, размечаются как канонические термины. Англицизмы, используемые только в профессиональном жаргоне без нормативной фиксации, размечаются как квазитермины. Критерий — наличие единицы в официальных глоссариях или нормативных документах домена.

## 5. Если единица не подходит ни под одну категорию

Если кандидат не может быть отнесён ни к одной из четырёх категорий терминологического статуса, он получает метку **«неопределённый статус»** и выносится на арбитраж координатора с доменным экспертом. Доля таких единиц фиксируется отдельно; если она превышает 5 % от общего объёма подвыборки, система категорий пересматривается и уточняется.

Для концептуальных категорий: если единица не вписывается ни в одну из 8–12 категорий домена, она получает метку **«прочее»** и рассматривается как кандидат для расширения таксономии.

## 7. Инструменты

**Чем выполняется анализ:**

| Этап | Инструмент | Версия / параметры |
|------|-----------|-------------------|
| Лемматизация | `pymorphy3`, `spaCy` (модели `ru_core_news_sm`, `en_core_web_sm`) | pymorphy3 3.1+, spaCy 3.7+ |
| Удаление стоп-слов | Кастомный список + стандартные списки `nltk`, `spaCy` | Расширенный список для каждого домена |
| Статистическое извлечение | `scikit-learn` (TF-IDF), `rake-nltk` (RAKE), кастомная реализация C-Value | TF-IDF: `max_features=10000`, `ngram_range=(1,3)`; RAKE: стандартные параметры |
| Нейросетевое извлечение | `KeyBERT`, `sentence-transformers` | Модель: `paraphrase-multilingual-MiniLM-L12-v2`; `top_n=20` на документ |
| Векторная кластеризация | `hdbscan`, `scikit-learn` (K-Means) | HDBSCAN: `min_cluster_size=10`, `min_samples=5`; K-Means: `k` определяется по Silhouette Score |
| Метрики качества | `scikit-learn` (Precision, Recall, F1), кастомный расчёт Precision@k, Recall@k | Бутстреп: 1 000 повторных выборок |
| Экспертная разметка | `Label Studio` | Версия 1.12+; шаблон многоклассовой классификации с связями |
| Статистический анализ | `Python` (`pandas`, `numpy`, `scipy`) | Каппа Коэна: `sklearn.metrics.cohen_kappa_score`, `statsmodels.stats.inter_rater` |

**Настройки и параметры, влияющие на результат:**
- Выбор модели эмбеддингов (`paraphrase-multilingual-MiniLM-L12-v2` vs `LaBSE` vs `mBERT`).
- Порог уверенности модели для отбора кандидатов в термины.
- Параметры кластеризации (`min_cluster_size` в HDBSCAN).
- Список стоп-слов (доменно-специфичный).
- Размер контекстного окна при извлечении.

Все параметры фиксируются в файле конфигурации `config.yaml` в репозитории для обеспечения воспроизводимости.
